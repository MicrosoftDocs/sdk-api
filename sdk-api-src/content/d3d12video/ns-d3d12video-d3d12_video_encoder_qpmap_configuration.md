## -description

Defines the configuration for QPMap as input for [D3D12_FEATURE_DATA_VIDEO_ENCODER_SUPPORT2](ns-d3d12video-d3d12_feature_data_video_encoder_support2.md).

## -struct-fields

### -field Enabled

Indicates if QPMap is enabled.

### -field MapSource

A [D3D12_VIDEO_ENCODER_INPUT_MAP_SOURCE](ne-d3d12video-d3d12_video_encoder_input_map_source.md) specifying the input source.
