## -description

Encapsulates a list of graphics commands for video encoding. This interface inherits from [ID3D12VideoEncodeCommandList3](nn-d3d12video-id3d12videoencodecommandlist3.md) and adds the [EncodeFrame1](nf-d3d12video-id3d12videoencodecommandlist4-encodeframe1.md) and [ResolveEncoderOutputMetadata1](nf-d3d12video-id3d12videoencodecommandlist4-resolveencoderoutputmetadata1.md) methods.
